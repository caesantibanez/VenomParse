# VenomParse
A Python Pipeline for Venom Orthology and Annotation Synthesis

**Overview**
VenomParse is a custom, command-line Python toolkit built using standard libraries (such as argparse and csv) and data manipulation libraries like pandas. It is designed to bridge the gap between large-scale orthology inference and functional toxin annotation. It automates the parsing, integration, and summarization of outputs from OrthoFinder and the venom-prediction tool TAPAI, preparing the data for evolutionary rate modeling (e.g., CAFE) and final statistical reporting.

**Core Functions and Modules**

**Directory Traversal and FASTA Parsing:**
The script iteratively scans through large-scale genomic outputs (e.g., 1,000+ OrthoFinder orthogroup directories). It reads the compiled FASTA files for each orthogroup, systematically parsing the sequence headers to extract specific species identifiers (e.g., isolating prefixes such as Ahentzi from complex assembly headers).

**Functional Annotation Integration:**
VenomParse cross-references the parsed orthogroup sequences with the functional classification outputs generated by TAPAI. It evaluates each sequence within an orthogroup, categorizing and tallying them based on their predicted status (venomous vs. non-venomous) and their identified functional domain architectures (e.g., Ank, Peptidase M10).

**Data Aggregation and Matrix Generation:**
The script calculates absolute sequence counts per species across all analyzed orthogroups. It dynamically filters the data based on user-defined thresholds (e.g., removing single-taxon OGs or filtering out extreme copy-number disparities >30) to prevent misassemblies from skewing downstream analyses.

**Automated CSV Output:**
The final processed data is exported into structured CSV tables. These tables include species-by-orthogroup matrices formatted specifically for CAFE evolutionary rate analyses, as well as summary tables detailing the lineage-specific distributions of venomous sequences (orphan OGs) and novel domain bindings across the phylogeny.
